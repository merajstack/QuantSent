<h1>QuantSent – AI-Powered Stock Market Intelligence Platform</h1>

<p>
QuantSent is a <strong>web-based financial intelligence platform</strong> that combines 
<strong>real-time stock market data</strong> with <strong>AI-driven sentiment analysis</strong>, 
helping investors, traders, and enthusiasts make <strong>smarter investment decisions</strong>.
</p>

<hr />

<h2>Core Purpose</h2>
<p>
QuantSent centralizes <strong>stock analysis, sentiment evaluation, and portfolio tracking</strong> 
into one intuitive dashboard – replacing the need for multiple tools.
</p>

<hr />

<h2>Key Features</h2>

<h3>Real-Time Stock Analysis</h3>
<ul>
  <li><strong>Live Stock Search</strong> (AAPL, TSLA, MSFT…)</li>
  <li><strong>Auto-refreshing Prices</strong> (every 2s)</li>
  <li><strong>Market Status Indicator</strong> (US market open/close)</li>
  <li><strong>Interactive 7-Day Charts</strong></li>
</ul>

<h3>AI-Powered Sentiment Analysis</h3>
<ul>
  <li><strong>News Sentiment Scoring</strong> (Positive, Negative, Neutral)</li>
  <li><strong>Curated Financial News Feed</strong></li>
</ul>

<h3>Comprehensive Financial Metrics (via Finnhub API)</h3>
<ul>
  <li><strong>Valuation</strong>: P/E, PEG, P/B, P/S</li>
  <li><strong>Profitability</strong>: ROE, ROA, Profit Margin</li>
  <li><strong>Liquidity/Debt</strong>: Current Ratio, Debt-to-Equity, Beta</li>
  <li><strong>Performance</strong>: EPS, Dividend Yield, Market Cap</li>
</ul>

<h3>Personal Watchlist</h3>
<ul>
  <li><strong>Unlimited Stocks</strong> with persistent storage</li>
  <li><strong>Portfolio Overview</strong> (real-time updates)</li>
  <li><strong>Sentiment Tracking</strong> per stock</li>
</ul>

<h3>Advanced User Experience</h3>
<ul>
  <li><strong>Responsive Design</strong> (desktop/mobile/tablet)</li>
  <li><strong>Dark/Light Theme</strong></li>
  <li><strong>Smooth Animations & Clean Navigation</strong></li>
</ul>

<hr />

<h2>Technical Architecture</h2>

<h3>Frontend</h3>
<ul>
  <li>React 18 + TypeScript</li>
  <li>Tailwind CSS + Radix UI</li>
  <li>Recharts (visualization)</li>
  <li>React Router & React Query</li>
</ul>

<h3>Data Sources</h3>
<ul>
  <li><strong>Twelve Data API</strong> → real-time prices</li>
  <li><strong>Finnhub API</strong> → financial ratios</li>
  <li><strong>News API</strong> → sentiment-driven news</li>
</ul>

<h3>Optimizations</h3>
<ul>
  <li>Lazy loading & smart auto-refresh</li>
  <li>Local storage for persistence</li>
  <li>Graceful error handling</li>
</ul>

<hr />

<h2>Use Cases</h2>
<ul>
  <li><strong>Day Traders</strong> → Real-time monitoring + AI sentiment</li>
  <li><strong>Long-term Investors</strong> → Ratio-based fundamental research</li>
  <li><strong>Market Enthusiasts</strong> → Curated financial news</li>
  <li><strong>Portfolio Managers</strong> → Organized watchlist tracking</li>
</ul>
